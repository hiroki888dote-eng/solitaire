# ソリティア

スマホで遊べるソリティア（クロンダイク）です。iPhone のホーム画面に追加すると、アプリのように全画面で遊べます。

- カードをタップ → 置ける場所へ自動で移動
- 指でドラッグ → 好きな場所へ移動
- 右上の山札をタップ → カードを1枚めくる
- 山札がなくなり場札が全部表向きになったら、自動で片付け
- 必ずクリアできる配り方だけを出す（コンピューターが解き方を確かめてから配る）
- 「目安の手数」を表示し、クリア時に目安との差で採点
- 途中の状態は自動保存
